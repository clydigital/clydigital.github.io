# Investment intelligence edition v1 — staged reader contract
This is a generic renderer, not an investment engine. Manual research supplies an owner-reviewed JSON edition inside the existing authenticated index page body, in a hidden plain-text element with id ps-investment-intelligence-data. Use an HTML-escaped JSON string (especially & and <); never script tags. The public repository contains presentation code only. No new table, cron, automatic investment write, or dossier dependency. Existing protected pages and decision tickets remain intact. The edition is supplemental to the existing ledger, not trade authority.
 
Required top level: contract = ps-investment-intelligence/1, asOf = ISO timestamp. Optional sections: macro (score, evidenceStatus, verdict, previousScore, previousAsOf, why, opportunityCost, recession, credit, inflation, seasonality, deployment, invalidation, evidence); rotation (verdict, why); sectors, divergences, technicals, universe, opportunities, scenarios, hedges, portfolio, history. See renderer for field names. The universe includes uncovered candidates (id, name, ticker, sector, industry, theme); opportunities extend those identities, plus independent discoveries. Use stable listing-specific IDs, not bare ambiguous symbols. Do not mark verified when evidence is stale or absent. For recommendations include action, evidenceStatus, why, business, valuation, downside, catalyst, invalidation, portfolioFit, scenarios and hedges; supporting evidence rows contain claim, asOf, url, side. Evidence status is reviewed by the manual author, not inferred by the reader. No automatic execution. Dossiers are downstream personal reading only.
 
Integration: run existing auth/owner RLS checks first; mount on index, sectors, ideas, research, portfolio, decisions, archive. Missing edition is visibly missing, never a generated neutral score. The current independent quote feed must remain until a separate parity migration verifies all consumers and broker/FX coverage; this branch does not retire or reschedule any feed.
 
Acceptance: Node regression tests, verify full dynamic universe and stale/missing rows, authenticated browser screenshot and responsive checks, source-date and private RLS readback, manual edition writer with escaped payload and revision history, existing action log routing regression, legacy quote consumer migration and explicit release approval. No live-data or production claim from this branch alone.
